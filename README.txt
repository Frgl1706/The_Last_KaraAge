文化祭 唐揚げ屋台 HTML セット

■ ファイル
- 07_updated.html : 更新済みの単一HTML
- images/01.png ～ images/08.png : サイトで使用する画像を配置してください（PNG / 1920×1080推奨）
- fonts/AprilGothicOne-R_v1.01.ttf : エイプリルゴシックのフォントファイルを配置してください

■ デザインの更新
- 全体のアクセントをオレンジ系に統一
- ホーム画面をエイプリル系の大見出しとポスター調レイアウトに変更
- 情熱タブ内の細かな英字ラベル／工程タグを削除
- 工程カードの選択アニメーション、発光切り替え、火花エフェクト、ハプティクス、スクロール進捗、パララックス、段階的なスクロール表示を追加
- ハプティクスは navigator.vibrate に対応するブラウザー・端末のみ動作します

HTMLと images / fonts フォルダーは同じ階層に配置してください。
フォントファイルおよび画像ファイル自体は今回の更新素材に含まれていません。
Firebaseの共有レビュー・投票を使用するには firebaseConfig の設定値が必要です。
